01 / Choose by context

The real question changes with the player

These four phrases belong to the same class-choice page because they ask for a recommendation, but each needs its own evidence and caveat.

Solo

Best solo class

Look for stealth, escape tools, self-sufficiency and a way to recover from a bad engagement.

PvP

Best PvP class

Separate duel pressure and mobility from a class that is simply easy to learn.

PvE

Best PvE class

Compare clear speed, range, control and the ability to stay useful against bosses and minions.

Beginner

Best beginner class

Prefer a readable weapon loop and a forgiving way to contribute while learning the extraction cycle.

What the collected material signals

The class references do not give one identical answer for every mode. One collected comparison describes Sorcerer as the strongest overall option, Mercenary as a forgiving starting point and Shadowstrix as the solo pick. Another dated comparison separates Solo and Trio results, placing ranged damage higher in Trios and stealth or self-sufficiency higher in Solo play.

Use those statements as source-attributed signals, then open the Classes hub and the relevant Builds page before committing to a class.

02 / Class-choice FAQ

Keep adjacent intents separate

Is Best Class the same page as Tier List?

No. Best Class helps a player choose by context. Tier List records a ranking comparison with its source date and mode split.

Can one class be best for every player?

The collected material does not support collapsing every context into one answer. State the mode, weapon path and evidence behind any recommendation.

Where should I go after choosing a class?

Use Classes for the roster, Builds for a setup, and Solo for the separate single-player question.
