Hammer: close distance and clear space

The collected class source describes Hammer Dash as an engage tool and Earthshaker as an area-damage option once Mercenary is in the middle of the fight. This route suits players who want the weapon itself to start the exchange and create pressure immediately.

Use the route when

  • You need a direct way to enter melee range.
  • Several enemies are close enough for area damage to matter.
  • You prefer a small, readable sequence while learning the game.

The source material does not provide a complete verified talent or affix table for this page, so exact thresholds are left to the current in-game build rather than filled with guesses.

Sword and Shield: measured offense

The collected class notes describe gradual stacks that can pay off through Stacked Slash, alongside timely parries with Perfect Block. This route trades some of Hammer's direct aggression for a more deliberate exchange.

Use the route when

  • You want defensive timing to be part of the build.
  • You prefer to wait for a punish window instead of forcing every engage.
  • You are building a foundation before experimenting with a more aggressive Hammer route.

Keep the shield path separate from the Hammer path when comparing gear; the collected material treats them as different ways to play Mercenary, not one interchangeable skill bar.
