Mistfall Hunter Cipher Guide

Find a Cipher during a run, read its clue words, match the correct camp NPC and use the Decipher option. The clue text is the safest lookup when a name and an older answer appear to conflict.

Mechanism referenceLaunch-source snapshot
Version note

Cipher mappings and event rewards can change. Inspect the full item description in your current build before handing it over.

01 / The hand-in workflow

Six checks before you choose Decipher

  1. 01

    Extract with the item

    The collected references describe Ciphers as run loot that can come from protected chests, minions or bosses, and Soekja quests.

  2. 02

    Inspect the complete description

    Read the words near the end of the item text rather than relying on color, rarity or name alone.

  3. 03

    Match the clue family

    Use the table below to connect the two thematic words to a camp NPC.

  4. 04

    Speak to the NPC at camp

    Move the Cipher into the active character's inventory if the interaction is not visible.

  5. 05

    Select Decipher

    The collected source places the Decipher option at the bottom of the NPC interaction box.

  6. 06

    Separate ordinary and bonus rewards

    A currency result alone does not prove the clue match was wrong; first-time and repeat rewards may differ.

Common Cipher mistakes

  • Choosing an NPC from the Cipher name while ignoring the clue pair.
  • Sending Guidance or Return to Dew when the collected mapping places that pair with Soekja.
  • Reading Echo as one single answer: the named Echo example and the Echo clue word are treated separately in the source set.
  • Assuming every correct hand-in produces the same bonus material or rare reward.
  • Using an older launch or beta answer without checking the current item wording.

If Decipher is missing

Check that the Cipher survived extraction, is in the active character's carried inventory, the early camp progression is complete and the NPC is one of the seven listed above. If the option remains absent, compare the current patch notes and review date before discarding the item.

04 / Cipher FAQ

Fast answers at camp

Should I use the Cipher name or the clue words?

Use the name to find a row quickly, then confirm the full clue pair. The collected solution material treats clue words as the safer signal after localization or patch changes.

Who receives a Prayer Cipher?

The collected named example sends Prayer with Score / Plucking clues to Pip.

Why did the correct NPC give only currency?

The material lists several possibilities: a first-match bonus was already collected, the item produced its ordinary reward, the clue pair was read incorrectly or the game version changed.
